# pad

A Python CLI application for solving Dragonfjord's Puzzle-A-Day

## Usage

```bash
# Show help
pad --help

# Generate all possible solutions to the puzzle
pad generate data.csv

# Generate all possible solutions for a single day
pad solutions jan 31

# Solve a single day
pad solve jan 31

# Show a piece
pad piece L
```
